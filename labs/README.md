| CAL-LAB-002 / IT/OT zone | Um fluxo fictício viola a matriz de zonas? | **Implementado** |
| Inventário passivo | Dados anonimizados permitiriam calcular cobertura e lacunas? | Planejado |
| Tabletop de continuidade | Quais decisões de isolamento preservam segurança física? | Planejado |
| Comparação de protocolos | Que campos normalizados seriam suficientes para detecção? | Planejado |
